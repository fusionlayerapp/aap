# Security Policy

## Reporting a Vulnerability

If you discover a security issue in the Agent Action Protocol (AAP) specification, schema definitions, or validation tooling (`tools/aap-validate`), please report it privately to **[security@fusionlayer.app](mailto:security@fusionlayer.app)** rather than opening a public issue.

We acknowledge reports within 48 hours and aim to publish a coordinated fix and advisory within 14 days of verification.
